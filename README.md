# Pomorie Reports: civic data platform

Work in progress. A data platform that turns citizen reports from Pomorie, Bulgaria into
validated, routed cases and city-wide analytics, with an auditable reward ledger.

All data in this repository is synthetic. Nothing is sent to real authorities.
